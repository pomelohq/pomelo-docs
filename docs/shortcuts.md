# Keyboard shortcuts

The quick keys for driving the app. The same list lives in-app under
**Settings ▸ Shortcuts**.

## Global

| Keys | Action |
| --- | --- |
| `⌘N` | New workspace |
| `⇧⌘N` | New session |
| `⇧⌘S` | Shared services |
| `⇧⌘P` | Session — config editor + ENV |
| `⇧⌘0` | Activity Monitor (all workspaces) |
| `⇧⌘T` | Cycle theme |
| `⌘,` | Settings |

## Workspace

Apply to the **selected** workspace. Pull requests, Jira and Agent are hidden
on **main**.

| Keys | Action |
| --- | --- |
| `⌘1` | Services |
| `⌘2` | Pull requests |
| `⌘3` | Jira |
| `⌘4` | Database |
| `⌘I` | Agent |
| `⌘E` | Open in editor |
| `⌘T` | New terminal |
| `⌘J` | Toggle terminal drawer |
| `⌘B` | Toggle sidebar |
| `⌘0` | Activity (this workspace) |
| `⌘W` | Close focused terminal tab |
| `⌘K` | Clear the active terminal |

## Agent & database panes

| Keys | Action |
| --- | --- |
| `⌘−` / `⌘+` | Agent terminal — smaller / bigger text |
| `⌘⇧W` | Close the agent |
| `⌘R` | Database — refresh |
| `⌘↩` | Database — run the query |

::: tip Repo shortcuts vs keyboard shortcuts
The **⚡ menu** on a service card runs a repo's own commands (migrate, seed,
test). Those are declared in config — see
[Shortcuts & commands](./services#shortcuts-the-menu).
:::
